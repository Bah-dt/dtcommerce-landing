Politique de Confidentialité

Dernière mise à jour : 20 mai 2026

DT Commerce est une application de gestion commerciale développée par DT Tech Deals (Conakry, République de Guinée). La présente politique décrit comment vos données sont collectées, utilisées, stockées et protégées.

1. Responsable du traitement

  • Éditeur : DT Tech Deals
  • Contact : dttech.guinee@gmail.com
  • Application : DT Commerce (Android, iOS, Windows)

2. Données collectées

DT Commerce fonctionne en mode local-first. Aucune donnée n'est transmise à des serveurs distants sans votre activation explicite de la synchronisation cloud.

2.1 Données stockées localement (sur votre appareil)

  • Informations boutique : nom, adresse, NIF, logo, téléphone
  • Comptes utilisateurs : nom, prénom, rôle, hash PIN (jamais le PIN en clair)
  • Catalogue produits : références, prix, stocks, photos
  • Clients : nom, téléphone, adresse, historique d'achat, crédits
  • Fournisseurs : raison sociale, contact, conditions
  • Ventes & paiements : montants, dates, modes
  • Employés (si module RH activé) : nom, fonction, salaire, pointages
  • Dépenses & comptabilité : catégories, montants, justificatifs

2.2 Données synchronisées (si sync cloud activée)

Les mêmes données ci-dessus sont répliquées chiffrées vers Supabase (hébergeur cloud, infrastructure AWS Europe). La synchronisation est désactivée par défaut.

2.3 Données d'activation de la licence

Pour valider votre clé d'activation, l'application transmet à nos serveurs :

  • La clé saisie (format DTC-XXXX-XXXX-XXXX-XXXX)
  • Un identifiant matériel anonyme de votre appareil (device ID local)
  • Le nom de la boutique active

Cet identifiant ne permet pas de vous identifier personnellement et sert uniquement à empêcher l'utilisation frauduleuse d'une clé sur plusieurs boutiques.

2.4 Données techniques

  • Rapports de crash anonymisés (si activés) : envoyés à Sentry pour diagnostic. Pas de PII.
  • Logs d'audit locaux : actions sensibles (login, suppression) stockés sur l'appareil uniquement.

2.5 Données NON collectées

  • Aucun tracking publicitaire
  • Aucune empreinte d'appareil ni identifiant publicitaire
  • Aucune localisation GPS
  • Aucun accès aux contacts, SMS ou autres apps
  • Aucune revente à des tiers

3. Finalités du traitement

  • Gestion commerciale : tenir la comptabilité, gérer stock, facturer
  • Synchronisation multi-appareils (si activée) : accès depuis plusieurs téléphones/PC
  • Sauvegarde : éviter la perte de données en cas de panne d'appareil
  • Diagnostic technique : corriger bugs via rapports de crash anonymisés
  • Validation de la clé d'activation : empêcher la fraude

4. Base légale

  • Exécution du contrat : fournir le service applicatif
  • Consentement : pour la synchronisation cloud (opt-in explicite)
  • Intérêt légitime : diagnostics techniques anonymisés

5. Partage des données

Vos données ne sont jamais vendues ni cédées à des tiers. Elles sont uniquement traitées par :

  • Supabase (sous-traitant cloud) — si sync activée
  • Sentry (sous-traitant diagnostic) — uniquement traces techniques anonymisées

DT Tech Deals ne fait pas de publicité et n'utilise pas d'analytique tierce.

6. Durée de conservation

  • Données locales : tant que l'application est installée. Suppression complète via Réinitialiser l'application.
  • Données cloud (si sync) : conservées tant que la licence est active. Suppression sur demande dans 30 jours.
  • Sauvegardes : 10 dernières sauvegardes locales conservées en rotation.
  • Logs Sentry : 30 jours.

7. Sécurité

  • Chiffrement PIN : SHA-256 avec sel. Le PIN en clair n'est jamais stocké.
  • Stockage sécurisé : clés de chiffrement dans le keystore matériel (Android Keystore, iOS Keychain).
  • Verrouillage automatique : retour à l'écran PIN après inactivité.
  • Limitation tentatives PIN : blocage progressif après échecs répétés.
  • Connexions cloud : TLS 1.2+, RLS (Row-Level Security) Supabase par boutique.

8. Vos droits

Conformément aux principes RGPD-like (loi guinéenne sur la protection des données) :

  • Accès : consulter toutes vos données via l'app
  • Rectification : modifier toute donnée via les écrans dédiés
  • Effacement : suppression complète via Réinitialiser l'application ou demande email
  • Portabilité : export complet via Réglages → Sauvegarde → Exporter
  • Opposition au traitement : désactiver la sync cloud à tout moment

Pour exercer un droit : dttech.guinee@gmail.com. Délai de réponse : 30 jours.

9. Cookies / Traceurs

DT Commerce est une application native, n'utilise pas de cookies. Aucun traceur publicitaire.

10. Enfants

DT Commerce est destiné à un usage professionnel. Réservé aux personnes majeures (18 ans).

11. Transfert international

Les données synchronisées sont stockées sur les serveurs Supabase (région Europe). Le transfert depuis la Guinée vers l'UE est encadré par les clauses contractuelles types Supabase.

12. Modifications

Cette politique peut évoluer. Toute modification substantielle sera notifiée dans l'application et par email aux utilisateurs cloud.

13. Réclamation

En cas de désaccord : contacter d'abord dttech.guinee@gmail.com. À défaut de réponse satisfaisante sous 30 jours, vous pouvez saisir l'autorité de contrôle compétente.
